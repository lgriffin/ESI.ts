      An endpoint definition built from the generated route table: the path, method and whether a token is needed come from the spec's operation, and so do a text response and an empty answer read as [] when the spec declares them. Everything else is the custom client's (method name, argument order, query parameters, body builder, schemas, cursor handling), and the custom part wins where both say something, which is where a wire fix the spec gets wrong belongs. See guides/CLIENT-ARCHITECTURE.md, plan step 2.
