    Class EsiApiFactory

    One legacy domain client on its own ApiClient.

    The nine named create*Client methods are deprecated since 11.0.0 in favour of createEsi and esi.as(identity) from @lgriffin/esi.ts/client, and are removed no earlier than 12.0.0. EsiApiFactory.createClient is not deprecated.

    Example

    import { createEsi } from '@lgriffin/esi.ts/client';

    const esi = createEsi({ userAgent: 'price-checker/1.0 (ops@example.com)' });
    const prices = await esi.public.markets.prices.get();
    const wallet = await esi
      .as(tokens.identity(characterId))
      .character(characterId)
      .wallet.get();
