    Class EsiApiFactory

    One custom domain client on its own ApiClient.

    EsiApiFactory.createClient is the way to build one by name. The nine named create*Client methods have been deprecated since 11.0.0 in favour of it; removing them needs a future major release, and none is scheduled. For several domains on one shared pipeline, use EsiClientBuilder.

    Example

    import { EsiApiFactory, MarketClient } from '@lgriffin/esi.ts';

    const market = EsiApiFactory.createClient('market', {
      userAgent: 'price-checker/1.0 (ops@example.com)',
    }) as MarketClient;
    const prices = await market.getMarketPrices();
